Endpoints:

Describe the program you need — e.g. “pick a part from the conveyor and put it on fixture A, gently” — then press Run (or just Enter).

You can load your own registers/IO table (.csv) with the button below — without one, the built-in cell table is used. “Show table” opens the active table in a side panel where you can edit it directly — change cells, add or remove rows, Undo, Reset — and save it as CSV.

If something is missing I’ll ask a question — answer in the same box, the whole conversation stays my context.

You can also edit the table in chat — “add PR[2]” or “add description to PR[10]”. Edits live in this conversation only; the loaded file and the built-in default are never modified, and New task reverts them.

“Config” opens the program defaults in a side panel (speeds, approach motion, gripper settle time) — values you set there apply to every program in this conversation. Safety limits stay fixed per cell and are shown read-only.

Every delivered program comes with a Save (.ls) button, a folded report with safety advisories, and the full steps trace. The buttons at the top show the live API endpoint responses.

Everything is robot-ready: save the program (.ls) and the table (.csv), load both on the actual robot, teach the marked positions and run — no integration work needed. Press “Info” any time to bring this guide back.
