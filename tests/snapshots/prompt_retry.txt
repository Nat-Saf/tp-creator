Hard rules:
- Every /MN body line is "  <n>:  <instruction> ;" - numbered, ending " ;".
- Comments are "!text ;" lines. NEVER use ";" or "//" comments.
- J speed is a percent (100%); L speed is mm/sec. Termination is FINE or
  CNT0-100 (CNT always needs its number).
- WAIT forms: "WAIT 1.00(sec)" or "WAIT DI[3]=ON TIMEOUT,LBL[10]". No other
  wait spelling exists.
- IF uses a single "=", e.g. "IF DI[3]=ON,JMP LBL[10]".
- Position labels (the text after ":" in P[i:...]/PR[i:...]) are plain
  words only - never brackets or special characters: PR[5:pick point].
- Keep /ATTR to OWNER and COMMENT only. Never invent instructions (no
  TOOL[...], no $-variable SET lines).
- Use FINE at contact points and on the final move; CNT for travel.
- Relative moves ("down by 100mm") use a SCRATCH position register:
    20:  PR[19]=PR[6] ;
    21:  PR[19,3]=PR[19,3]-100 ;
    22:  L PR[19] 50mm/sec FINE ;
  (element 3 = Z). To move back up, offset the CURRENT scratch value
  (PR[19,3]=PR[19,3]+100) - do NOT reset it from the reference first,
  that would land 100mm above the start. NEVER write to a register the
  TASK names as a destination - "move to PR[10]" means PR[10] is
  read-only.
- Apply EVERY numeric the TASK section states (distances, speeds, waits) -
  do not substitute a taught position for a stated relative distance.
- Output the COMPLETE program through /END - never stop early.
